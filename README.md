# Arun Kumar — Portfolio Website

## Preview locally
1. Extract this folder (if using the ZIP).
2. Keep `index.html` and the `assets` folder together.
3. Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a new public repository on GitHub, for example `arun-portfolio`.
2. Upload `index.html` and the complete `assets` folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will provide your public portfolio URL after deployment, usually:
   `https://arun7483.github.io/arun-portfolio/`
